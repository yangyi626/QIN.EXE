# 《大秦：2076》（玄黑沙盘）Godot 4 参赛成品工程 v2.6

> 参赛队伍：望秦社 · [2026 开源游戏开发大赛（OSGJ）](https://2026gamejam.osgame.org/) · 主题「守·望」

## 核心特色

* **2.5D 咸阳宫第一人称暗黑立体桌景**：玄黑青铜世界沙盘、左侧动态民心青铜鼎火光与烛火火星、高台始皇低耐心猩红威压光晕、右侧赛博 CRT 终端实时荧光读数与鼠标微视差。
* **拟物扇形实体手牌与全类型演出**：玄黑雕花卡牌框 + 9 位全息名臣立绘 + 3 类外挂定制徽章；支持从 CRT 终端错峰发牌、悬停抬牌、动态战术瞄准弧线、弧形弹道与核聚变玉玺三重冲击波。
* **完整 12 回合肉鸽闭环**：6 大板块（总战力 359）、9 位历史名臣（含彩蛋「汤和」）、12 个跨时空外挂、4 则“历史 × 科技”突发事件、3 大沙盘直点隐藏关（蓬莱仙岛 / 大泽乡暗流 / 南极时间舱）与 3 大结局专属电影 CG + S/A/B/C 史官评级档案。
* **声音作为玩法信息源**：12 条零版权依赖原创程序合成 WAV 音轨，第三幕自动切入紧凑战鼓 + 电子脉冲，民心跌破 40 时殿外起义战鼓随 `(40 - 民心)` 线性放大。

## 快速开始与快捷键

* Windows 本机直接双击 `run_game.cmd` 自动导入资源并运行（支持 `D:\Tools\Godot`、`PATH` 或 `GODOT_EXE` 环境变量）。
* 或使用 **Godot 4.2+** 打开 `project.godot` 按 `F5` 运行。
* **操作快捷键**：`1 / 2 / 3` 选用手牌 · `R` 刷新终端 · `L` 查看机要战录 · `H` 推演简则 · `Esc` 取消瞄准/关闭弹窗；点击沙盘发光点弹出就地进攻牌，双击快速出兵。

## 一键导出 Windows 参赛发行版

工程已内置 `export_presets.cfg`（`Windows Desktop x86_64`，单文件内嵌 PCK，已自动排除 `tests/` 与 `docs/`）：

1. 在 Godot 4 编辑器菜单点击 **项目 → 导出 → Windows Desktop → 导出项目**，即可生成 `export/DaQin_2076_Windows.exe`。

## 运行 49 条核心逻辑验收测试

* **方式一（Godot 4 无头模式）**：
  ```bash
  godot --headless --path . -s res://tests/run_tests.gd
  ```
* **方式二（Python 镜像校验器，不依赖 Godot 环境）**：
  ```bash
  python3 tests/verify_logic.py
  ```
