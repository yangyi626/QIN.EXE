# 《大秦：2076》（暂定名：玄黑沙盘）游戏策划案 v2.1

> **v2.1 说明（2026-11-22）：** 本版与 `docs/规则与数值定案_v1.md`、`data/game_data.json` 对齐，规则和数值冲突时以后两者为准。改动处标〔改〕，新增处标〔新〕，完整对照见文末附录 A。文中的数值来自手写机器人的模拟，没有真人试玩数据，试玩后需要复核。

## 一、项目概览

* **〔新〕参赛队伍：** 望秦社

* **备选名称（按风格分类，待团队定名）：**

  * **厚重 / 扣题「守·望」风：** 《大秦守望》 / 《玄黑望世》 / 《咸阳望》

  * **赛博 / 直观好懂风：** 《大秦：2076》 / 《玄黑沙盘》 / 《大秦沙盘》 / 《赛博大秦》 / 《秦始皇的未来终端》

  * **网感 / B 站传播风：** 《陛下，这玩意叫无人机》 / 《开挂大秦：从咸阳到全球》 / 《始皇的赛博外挂》

* **参赛赛事：** [2026 开源游戏开发大赛（OSGJ）](https://2026gamejam.osgame.org/)

* **参赛主题：** 官方主题 **「守·望」**

* **主攻方向：** 方向 6 —— **未来想象**（结合历史文化与 AI、未来科技，探索跨时空互动表达）

* **〔新〕评分侧重点：** 提交时可在创意、玩法、叙事、视听四个维度中分配 2 个侧重点，每点占游戏质量评分的 10%。本作选 **创意** 与 **玩法**：卖点一句话能讲清（秦始皇 + 现代外挂 + 赛博沙盘），核心取舍是“民心既是血条又是货币”。视听不作主攻：第三方素材占比超过 50% 的作品不参评最佳视听奖，而本作计划使用官方素材包和免费音效；AI 生成素材是否计入第三方，需向组委会确认。最佳单项奖按对应维度排序，不计这个侧重点。

* **游戏类型：** 3D 第一人称暗黑桌面策略 + 肉鸽构筑（Roguelike）

* **开发引擎：** Godot 4（3D 场景壳子 + 2D 立绘全息投影，支持 Windows 10/11 导出）。〔新〕逻辑与表现分离：`scripts/core` 只放纯逻辑，`scripts/ui` 只放场景与界面，接口见 `docs/interface.md`。

* **单局时长：** 5 ~ 8 分钟（高度契合评委与互评 40% 的短时试玩节奏）。〔新〕建议：摊到 12 回合是每回合 25 ~ 40 秒，每次拍棋子的演出控制在 2 ~ 3 秒内，并允许跳过。

* **核心扣题「守·望」：**

  * **「守」——守住民心与文明底线：** 民心值既是血条也是开挂货币。玩家不仅要替始皇平定天下，更要在乱世与科技暴走的诱惑中，**守住万民之心**，守住大秦不二世而亡的底线。

  * **「望」——跨时空的凝望与期盼：** 公元前 221 年的咸阳宫透过赛博终端**望向** 2076 年的未来科技；未来人（玩家）与历代 AI 名臣跨越两千年回**望**历史，共同守望人类文明的最终走向。〔新〕玩法上，三个隐藏关都要玩家主动“望”向沙盘边缘（拉近镜头、派无人机侦查、破译反光点）才能发现。

## 二、核心玩法与数值框架

### 1. 三大核心数值

* **民心值（0 ~ 100，初始 60）：** 既是**血条**，也是**买外挂的货币**（一物多用，制造强策略取舍）。降到 0 立刻触发“大泽乡起义”失败。桌角的青铜鼎火光与殿外喧哗声实时反映民心高低。

* **统一进度（0 / 6）：** 沙盘上的全球 6 大板块全部染成大秦玄黑色即胜利。

* **始皇耐心（12 回合倒计时）：** 防止玩家无脑种田刷民心，逼迫玩家在“超时斩首”和“透支民心开挂”之间走钢丝。〔新〕模拟发现，原案里【全息假始皇】可无限购买、【赛博焚书】可续买，会让这个倒计时形同虚设，所以这两张牌已加限制，见第五节。

### 2. 单回合循环（Core Loop）

1. **开局 30 秒高光钩子（专为互评优化）：** 第 1 回合免费赠送 1 次“无人机蜂群打击”或“首次 AI 名臣召唤”（〔改〕免费只对这两类牌生效，只此一次），确保评委在试玩前 1 分钟内立刻体验到“玄黑沙盘 + 赛博光轨 + AI 互怼”的核心爽点。

2. **回合开始：** 始皇耐心 -1。〔改〕按固定顺序结算：先加丝路红利（攻克西域后 +5），再扣贷款（跨时空贷款的后续扣减），再触发韩信的随机打击，最后刷新终端。在场的 AI 名臣触发常驻技能，并在沙盘对面发表针对当前局势的实时吐槽。

3. **终端刷新（肉鸽核心）：** 桌右边的赛博终端随机刷出 **3 张全息卡片**（名臣池 + 外挂池混抽，已在场的名臣、已买过的一次性牌不再出现）。玩家可消耗民心兑换，或花 `5 民心` 刷新。〔改〕刷新不占行动，每回合最多刷新 3 次。

4. **〔改〕每回合 2 次行动：** 购买外挂、召唤名臣、造楼船、点隐藏关（南极时间舱除外）各占 1 次行动，用完后只能刷新、常规进攻或结束回合。模拟里这条规则对难度影响最大：每回合 1 / 2 / 3 次行动，新手玩家的通关率分别是 52% / 72% / 89%。

5. **实体交互（拍棋子）：**

   * **民生/黑科技** $\rightarrow$ 拍在沙盘大秦本土，触发回民心或特殊机制。

   * **现代武器** $\rightarrow$ 拍在任意未占领的敌对板块上，触发微缩轰炸演出并扣减敌方战力。武器和韩信不受前置板块限制。

   * **历史名臣** $\rightarrow$ 插入终端槽位，名臣以青色全息投影站在沙盘对面（最多同时在场 2 位，新召唤可替换旧位）。

6. **常规推进（保底操作）：** 若本回合不想开挂，可直接点击沙盘发动“常规秦军进攻”（不扣民心，但打后期强敌吃力）。〔改〕**每回合 1 次，不占行动次数**；常规秦军基础战力为 20，对不同板块有效率折扣，见第三节；南亚、西亚需先占领西域，欧罗巴需先占领西亚。纯靠常规进攻要 40 次攻击才能推完，不可能通关，必须开挂。

7. **结算与事件：** 判定胜负；每 3 回合触发 1 次“历史 $\times$ 科技”二选一突发事件（具体事件库见下文第 4 小节）。

### 3. 〔新〕结算细节与 UI 防呆规范

* **常规进攻对每个板块的效率：** 草原 1.00、西域 1.00、南亚 0.75（【青霉素】生效的当回合变为 1.00）、西亚北非 0.60、欧罗巴 0.30、新大陆 1.00。伤害累计，不回血，取整向下。

* **民心上限：** 回血最多到 100；【商鞅】在场时上限为 80。

* **一次性牌：** 水泥直道、AK-47 兵马俑、跨海铁甲舰每局只能买 1 次。

* **义务教育：** 须在当回合常规进攻之前购买；购买后本回合不能常规进攻。

* **胜负判定：** 最后一块板块被攻克的瞬间立即结算，按当时民心判千古一帝（$\ge 60$）或赛博暴君（$< 60$）。

* **UI 防呆可视化（降低评委理解成本）：**
  * 终端上方显示 **2 颗发光行动点数豆** 与 **常规进攻可用图标**，消耗后立刻熄灭。
  * 当回合执行过常规进攻后，自动将【义务教育】按钮置灰并悬停提示“本回合已进攻，不可购买”。
  * 刷新按钮旁直接标注剩余次数（如 `刷新 3/3`）。

每 3 回合随机抽取 1 则，保证基础选项代价约等于 `10 民心`（汤和在场时民心扣减减半为 `5`），贴合数值模拟曲线：

| :--- | :--- | :--- | :--- |
| **1. 赛博舆情监控** | 咸阳街头流传“方士用铁鸟摄魂”的谣言，人心浮动。 | **全网控评删帖**：直接压下谣言，但民众心生恐惧（`-10 民心`，汤和在场 `-5`）。 | **公开无人机表演**：安抚民众情绪，但本回合剩余行动数 `-1`（若已用完则 `-10 民心`）。 |

## 四、沙盘隐藏关卡（绝地翻盘与探索惊喜）

零额外 3D 建模成本，直接以微弱视觉异常点藏在现有沙盘中，点击触发高回报事件。〔改〕蓬莱仙岛和南极时间舱只在民心低于 50 时出现，确保其“绝地翻盘”定位。

1. **【蓬莱仙岛】拆穿徐福骗局**

   * **位置与触发：** 沙盘东海迷雾边缘有微弱的青色数据乱码，拉近点击或派无人机侦查触发。〔改〕仅当民心 < 50 时出现，每局一次，占 1 次行动。

   * **内容与奖励：** 发现徐福带着国库黄金在海岛建度假村。选择“当众拆穿并散财于民” $\rightarrow$ **民心 +35**（代价：秦始皇长生梦碎，耐心 -1 回合）。

2. **【大泽乡暗流】微服私访**

   * **位置与触发：** 当民心值低于 `40` 时，大秦本土角落会冒出一颗极小的暗红色火星，点击触发。〔新〕火星一旦出现就保留到被点击，即使民心之后回升；每局一次，占 1 次行动；点击需要场上有名臣。

   * **内容与奖励：** 暴雨中陈胜吴广正欲起义。〔改〕定案为单一路径：**派在场 AI 名臣前去安抚** $\rightarrow$ **民心 +25**，消除起义隐患（MVP 阶段砍掉“空投物资”分支，保持逻辑简洁）。

3. **【南极冰层】穿越者的时间舱**

   * **位置与触发：** 沙盘最下方边缘藏着一个微小金属反光点，消耗 1 次终端刷新能量破译触发。〔改〕仅当民心 < 50 时出现，每局一次；占用当回合的刷新次数（计入每回合 3 次的上限）。

   * **内容与奖励：** 找到自己穿越时坠落的逃生舱，获取未受损的种子库与医疗包 $\rightarrow$ 〔改〕**直接恢复 `民心 +50`**（合并原“金色民生外挂 + 民心 +20”），且不消耗本回合行动。

## 六、剧情节奏与三大结局

〔改〕因模拟显示守民型打法平均 9 回合结束、速通型约 7 回合，**剧情幕次与音乐氛围改为按“已占领板块数”触发**，确保无论快慢都能完整体验高潮：

* **开场（30 秒）：** 公元前 221 年，你携带未来推演终端坠落咸阳宫。秦始皇将你按在沙盘前立下赌约：12 回合内一统寰宇、守住大秦江山，成则封万世国师，败则斩首。

* **第一幕（已占领 0 ~ 1 块，蜜月期）：** 科技兴国、轻松扩张，首次召唤 AI 名臣，体验跨越两千年凝望与改写历史的爽感。

* **第二幕（已占领 2 ~ 3 块，诱惑与撕裂）：** 面对强敌与倒计时，被迫动用现代热武器；民心下跌、殿外喧哗，在场 AI 名臣围绕“强权统一”与“守住民心”展开激烈互怼。

* **第三幕（已占领 4 ~ 5 块，终局走钢丝）：** 决战欧罗巴与跨海美洲，BGM 切换为紧凑战鼓+电子脉冲，在“透支民心强推”与“稳健守望”间做出最终抉择。

### 三大结局（直接回应「守·望」）

1. **【千古一帝 · 守望大同】**（统一全球 + 民心 $\ge 60$）：大殿金光大盛，始皇放下长剑，感叹长生不在蓬莱而在“万民归心”。终端提示：`你守住了人心，人类文明提前两千年望见大同。`

2. **【赛博暴君 · 孤城独望】**（统一全球 + 民心 $< 60$）：沙盘全黑但殿外火光冲天，始皇在阴影中狂笑。终端发出猩红警报：`疆域已统一，却无人与你共望未来。你创造了一个永恒的赛博牢笼。`

3. **【大泽乡 2.0 · 守城失据】**（民心归零 或 12 回合超时）：沙盘爆出无数红色起义光点，殿门被撞开，AI 名臣化作乱码消散，终端蓝屏。〔新〕数据里把“民心归零”和“超时”分成两个失败码（`lose_morale`、`lose_time`），演出共用，统计分开。

〔新〕内容合规：所有名臣台词和事件文案在入库前由成员逐条审核，确保符合社会主义核心价值观。

## 七、美术、音效与 Godot 4 技术规范

* **画风定位：** 「玄黑大秦 $\times$ 赛博低模」（3D 壳子 + 2D 立绘）。可合理复用官方【汤和信俗/永昌堡素材包】中的合规建筑纹样与民俗音效（使用前须核对原文件授权条款）。

* **4 色规范：** 玄黑（`#0B0D10`）、暗青铜（`#2C2620`）、火把鎏金（`#FFB347`）、赛博青（`#00F0FF`），低民心警报切猩红（`#FF2A2A`）。

* **Godot 4 场景树结构：**

  * `WorldEnvironment`：开启黑色体积雾（Fog）遮丑 + 辉光（Glow）拉满赛博发光质感。

  * `Camera3D`：固定机位，使用 `create_tween()` 切换。〔新〕MVP 先只留两个机位（俯视沙盘、右看终端）。

  * `Characters`：秦始皇做高台暗光剪影；名臣全用 `Sprite3D` 挂载 2D 立绘 + 全息扫描线 Shader。

* **声音作为玩法信息源（〔改〕作为加分项，不再作主攻）：** 战国编钟/低沉战鼓 + 电子合成音/电流滋啦声；民心跌破 40 时，殿外由远及近的**人群喧哗与起义战鼓**随 `(100 - 民心)` 线性放大。

* **〔改〕名臣互怼台词（本地词库方案）：** 台词在开发期用大模型批量生成，由成员人工筛选后写入本地 `data/lines.json`，每条不超过 25 字，运行时只读本地词库，不联网（彻底规避 API Key 暴露与额度消耗）。

* **〔新〕核心逻辑与表现分离：** `scripts/core` 不引用任何场景或界面节点，用 `tests/cases.json` 的 49 条用例验收；UI 只订阅 `GameCore` 的信号，不反向改状态。接口见 `docs/interface.md`。
