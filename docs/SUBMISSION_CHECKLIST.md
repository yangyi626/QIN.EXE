  - [ ] 检查 1280×720 窗口与 1920×1080 全屏下，扇形手牌、弹窗与名臣气泡均无遮挡或越界。

  - 在 Godot 4 编辑器使用已配置好的 `export_presets.cfg`（`Windows Desktop x86_64`，单文件内嵌 PCK）导出 `export/DaQin_2076_Windows.exe`，并在无 Godot 环境的纯净目录双击试玩验证。
