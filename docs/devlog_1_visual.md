# 开发日志 1：如何用 Godot 2.5D 桌景与全息 Shader，低成本做出赛博咸阳宫

> 参赛队伍：望秦社 · 作品：《大秦：2076》（玄黑沙盘）· 赛事：[2026 开源游戏开发大赛（OSGJ）](https://2026gamejam.osgame.org/) · 主题「守·望」

## 一、从“后台管理系统”到《邪恶冥刻》暗黑桌面

在 Game Jam 有限的周期里，我们最初尝试用纯代码在 Godot 4 中搭建 3D 沙盘：方块拼桌案、圆柱拼青铜鼎、正交相机俯视，再加上四周四个 `PanelContainer` 面板。但实机一跑，大家立刻发现一个致命问题——**画面失去了暗黑桌游的沉浸压迫感，看起来像一个网页后台管理系统**。

为了在短时间内把视觉质感拉升到成品级别，我们果断转向 **2.5D 第一人称精绘桌景 + 拟物实体卡牌** 的路线：

1. **严格锁死 4 色视觉规范**：全屏以玄黑（`#0B0D10`）与暗青铜（`#2C2620`）压低明度，只用火把鎏金（`#FFB347`）和赛博青（`#00F0FF`）作为交互聚焦光，民心跌破 40 时切入警报猩红（`#FF2A2A`）。
2. **第一人称桌景一体构图**：在 `assets/textures/bg_xianyang_desk.jpg` 中将左侧青铜鼎、正中玄黑世界地图沙盘、右侧复古赛博 CRT 终端与高台秦始皇剪影融为一体，再通过 `Control` 层的归一化 UV 映射 + 鼠标微视差（`±13px`）+ 武器落点震屏，让静态精绘底图真正“活”起来。
3. **砍掉所有粗糙占位按钮**：世界地图上的 6 大板块不再盖满不透明矩形按钮，而是改为纯发光玄黑/鎏金印记点（攻克后化作金印“秦”并连出金色补给线），悬停才展开铭文，点击才在身旁弹出青铜回纹情报牌。

## 二、让卡牌和名臣“立在桌面上”

为了让每次出牌都有实体桌游“拍棋子”的手感，我们做了三处关键细节：

* **雕花扇形手牌 + CRT 错峰发牌**：3 张终端卡片使用定制的玄黑青铜雕花卡框（`card_frame_obsidian.jpg`），以 `-3° / 0° / +3°` 扇形排布在桌沿底部。新回合或刷新终端时，卡牌会从右侧赛博 CRT 屏幕中错峰飞出落入手牌区；鼠标悬停时卡片弹性抬起并伴随轻脆翻牌音；指向型军事卡则会从卡顶拉出一条跟随光标的动态战术弧线，吸附到目标板块上预览命中后的剩余守军。
* **羽化全息名臣着色器（`shaders/hologram_2d.gdshader`）**：9 位历史名臣立绘全部通过 2D 全息 Shader 叠加扫描线、微弱电流闪烁与四边软羽化融合，漂浮在始皇御座两侧的暗影中，不再有生硬的方形贴图边缘；名臣吐槽直接以专属气泡弹在立绘旁，不被底部战报覆盖。
* **全屏暗角与始皇威压（`shaders/vignette.gdshader`）**：民心跌破 40 时，屏幕边缘自动浮现脉动猩红暗角，左侧青铜鼎火光与飘散火星同步变红；始皇耐心 ≤ 3 回合时，高台御座背后浮现猩红威压光晕。

## 三、零第三方版权风险的程序化动态音轨

为了在 OSGJ 中严控第三方素材占比，本作全部 **12 条 WAV 音效与环境音轨** 均由 Python 脚本按声学波形程序化合成，并直接把“声音作为玩法信息源”落进代码：

* **第一、二幕**：低沉玄黑青铜共鸣 + 细微烛火环境底噪（`bgm_ambient.wav`）。
* **第三幕（攻克 4~5 洲）**：自动无缝切入 120 BPM 紧凑战鼓 + 电子脉冲（`bgm_act3_drums.wav`）。
* **低民心预警（民心 < 40）**：殿外起义战鼓与低沉喧哗（`sfx_uprising_loop.wav`）随 `(40 - 民心)` 线性放大音量，玩家闭着眼睛都能听出大秦江山摇摇欲坠。
