# 开发日志 3：开挂平推全球的代价：我们如何用「守·望」重构肉鸽数值与隐藏关

> 参赛队伍：望秦社 · 作品：《大秦：2076》（玄黑沙盘）· 赛事：[2026 开源游戏开发大赛（OSGJ）](https://2026gamejam.osgame.org/) · 主题「守·望」

## 一、一句话讲清核心取舍：民心既是血条，也是货币

很多策略游戏容易陷入“资源越攒越多、后期垃圾时间”的通病。为了让评委在 5~8 分钟的短时试玩里全程神经紧绷，我们把整个游戏的核心收束成一条极其残酷的规则：

> **民心值（0 ~ 100）既是你的生命值，也是你从未来终端购买降维武器的唯一货币。**

* **只靠常规秦军必败**：6 大板块总战力经模拟从 240 上调至 **359**，后期欧罗巴常规进攻效率仅 0.30，纯靠常规部队需要 40 次攻击，12 回合内绝对推不完——你必须向未来科技借力。
* **无脑开挂也必败**：无人机蜂群（`-20`）、卫星制导重炮（`-30`）、核聚变传国玉玺（`-50`）威力毁天灭地，但每次拍下去都会透支大秦民心，民心一旦归零立刻触发“大泽乡 2.0”起义失败。
* **每回合 2 行动 + 1 免费常规进攻**：数值模拟表明，每回合 1 / 2 / 3 次行动对应的新手通关率分别为 52% / 72% / 89%；定案为 2 次行动后，玩家每回合都必须在“种田回血、召唤名臣、重火平推”之间做精确取舍。

## 二、用 49 条自动化测试用例锁死所有边界

肉鸽卡牌最怕出现“组合技结算顺序错乱”或“卡死死局”。我们把所有核心规则与边界条件写进了 `tests/cases.json`（共 **49 条用例**），同时提供 Godot 无头测试（`tests/run_tests.gd`）与零依赖 Python 镜像校验器（`tests/verify_logic.py`），覆盖：

* 回合开始固定结算序（丝路 `+5` → 跨时空贷款 `-15` → 韩信随机 25 伤害 → 刷新终端）；
* 诸葛亮与王安石折扣叠加单次取整、汤和不减半焚书反噬与贷款扣减；
* 商鞅 80 民心上限锁死、义务教育须在当回合进攻前购买、赛博焚书生效期间禁续买；
* 没抽到跨海铁甲舰时，依然可通过“强征造楼船”硬渡新大陆，确保整局绝不卡死。

## 三、三个沙盘隐藏关与三大结局：把「守·望」做成可玩机制

我们不希望主题「守·望」只停留在文案里，而是直接写进了玩法交互：

* **「望」——主动凝望沙盘边缘的 3 个绝地翻盘隐藏关**：
  * **蓬莱仙岛**（民心 `< 50`）：东海迷雾边缘浮现青色数据乱码，直接点击沙盘微光点拆穿徐福骗局，散财于民 `+35 民心`（代价：始皇长生梦碎，耐心 `-1`）。
  * **大泽乡暗流**（民心 `< 40` 后常驻至点击）：大秦腹地冒出暗红火星，派在场名臣微服安抚 `+25 民心`。
  * **南极时间舱**（民心 `< 50`）：沙盘最南端出现金属反光，消耗 1 次终端刷新破译坠落逃生舱，不占行动直接 `+50 民心`。
* **「守」——三大结局专属 CG 与史官评级**：
  * 统一全球且民心 ≥ 60 → **【千古一帝 · 守望大同】**（金色晨光古都 CG，民心 ≥ 80 获评 **S · 盛世千古**）；
  * 统一全球但民心 < 60 → **【赛博暴君 · 孤城独望】**（猩红监控穹顶 CG，你赢得了疆域却创造了赛博牢笼）；
  * 民心归零或 12 回合超时 → **【大泽乡 2.0 · 守城失据】**（青铜鼎倾覆与碎裂 CRT 终局 CG）。
